③ SEARCH — 検索・トレンド

📐 アーキテクチャ概要

📱 iOS (SwiftUI)

  • ✅ HomeView — トップストーリー + リスト
  • ✅ CategoryView — タブ別フィード
  • ✅ SearchView — キーワード + カテゴリ検索
  • ✅ BookmarkView — 保存済み管理
  • ✅ ArticleWebView — WKWebView 内蔵ブラウザ
  • ✅ NewsViewModel — MVVM データ管理
  • ✅ BackgroundFetchManager — BGTask 定期取得

🖥 Backend (Python · FastAPI)

  • ✅ RSS クローラー (feedparser)
  • ✅ キーワードフィルタリング
  • ✅ APScheduler 定期実行 (30分ごと)
  • ✅ SQLite 永続化
  • ✅ REST API /v1/articles
  • ✅ カテゴリ / キーワード / ページング
  • ✅ 手動クロール POST /v1/crawl
