## ✅ 实际操作步骤

### 1️⃣ 运行应用到模拟器或真机

```bash
# 打开 Xcode
open /Users/sundata/WorkBuddy/20260412212940/SeeNewsCore/SeeNews.xcworkspace

# 选择目标设备 (iPhone 13 Pro 或 iPhone 14 Pro 推荐)
# 点击 ▶️ Run 按钮
```

### 2️⃣ 获取每个截图

**截图 1: AI 分析功能**
- 打开任一新闻
- 点击「3秒で理解」
- 等待加载
- **Cmd + S** (模拟器) 或 **Side + Volume Up** (真机)
- 保存为 `screenshot_1_ai_analysis.png`

**截图 2: 无广告**
- 返回主页
- 切换用户为 Pro 账户 (可在设置中改)
- 滚动查看无广告界面
- **Cmd + S** 或 **Side + Volume Up**
- 保存为 `screenshot_2_no_ads.png`

### 3️⃣ 调整和上传

```bash
# 查看保存的截图
ls ~/Library/Developer/Simulator/Devices/*/data/Media/Screenshots/

# 或在 Finder 中找到截图
open ~/Desktop  # 复制截图到桌面

# 编辑截图 (可选：添加箭头/文字)
# 使用 Skitch 或 Preview.app
```

### 4️⃣ 在 App Store Connect 中上传

1. 登录 [App Store Connect](https://appstoreconnect.apple.com)
2. 选择应用 → 应用内购买 → 月度订阅
3. 找到「スクリーンショット」部分
4. 点击「+」添加
5. 选择 1-5 张截图
6. 点击「保存」
