# わりメモ 📱

**かんたん割り勘・旅行精算アプリ**

シンプルで使いやすい割り勘計算アプリ。登録不要、3タップで精算完了！

## ✨ 特徴

- 🚀 **登録不要** - すぐに使える
- 📱 **シンプルUI** - 直感的で分かりやすい
- 🎨 **日本向けデザイン** - 爽やかで見やすい
- 🧮 **自動計算** - 複雑な割り勘も一瞬で精算
- 📤 **かんたん共有** - LINEでスグ送信
- 💾 **履歴保存** - 過去のグループもいつでも確認

## 📋 主な機能

### グループ作成
飲み会、旅行、同棲など、シーンごとにグループを作成

```
例: 沖縄旅行、会社歓迎会、ルームシェア
```

### メンバー追加
名前だけでOK！ログイン不要

```
山田、佐藤、田中...
```

### 支払い記録
誰が、いくら、何を払ったかを記録

- 支払者を選択
- 金額を入力
- 内容を入力（居酒屋、ホテルなど）

### 自動精算
複雑な割り勘を自動計算

```
佐藤 → 山田へ 4,000円
田中 → 山田へ 4,000円
```

### LINE共有
精算結果をLINEでサクッと共有

## 🚀 クイックスタート

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/yourusername/warimeao.git

# プロジェクトフォルダに移動
cd warimeao

# Xcodeで開く
open わりメモ.xcodeproj
```

### 実行

1. Xcodeで開く
2. ターゲットを選択（iOS Simulator or デバイス）
3. `Cmd + R` を押して実行

## 📖 使い方

### グループを作成する

1. ホーム画面の「+」ボタンをタップ
2. グループ名を入力
3. カラーを選択
4. 「作成」をタップ

### メンバーを追加する

1. グループをタップして詳細画面へ
2. 「メンバー」の「+」ボタンをタップ
3. メンバー名を入力
4. 「追加」をタップ

### 支払いを記録する

1. 「支払い追加」ボタンをタップ
2. 支払者を選択
3. 金額を入力
4. 内容を入力
5. 「追加」をタップ

### 精算結果を確認・共有する

1. グループの詳細画面下部に精算結果が表示
2. 「LINEで共有」または「コピー」をタップ
