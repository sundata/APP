# App Review Notes（Build 4）

前回のご指摘に対応し、アプリの体験と表示を全面的に見直しました。

## Guideline 5.1.1(iv)

位置情報のシステム許可ダイアログ前に表示する独自画面のボタンを「位置情報を許可する」から「次へ」に変更しました。位置情報を使用しない「都市を選ぶ」経路も常に選択できます。

確認手順：初回起動 → 案内を進める → 場所の設定画面

## Guideline 4.3(b)

本アプリの主要体験を、占星術レポートから、ユーザー自身の継続的なセルフケア記録へ再設計しました。

- 5種類の気分チェックイン
- 毎日の小さなセルフケア項目と達成記録
- 160文字までの夜の振り返り
- 30日サマリー、最近7回の気分、気分バランス
- 天気と気分の組み合わせの振り返り
- カレンダー履歴と継続記録
- 記録データは端末内で処理・保存

占星術コンテンツは「今日のインスピレーション（任意）」内に折りたたみ、気分記録とは独立した補助的なエンターテインメント機能に変更しました。初期状態では閉じています。

確認手順：
1. 「今日」タブで気分とセルフケアを記録
2. 「記録」タブで日ごとの履歴を確認
3. 「リズム」タブで30日間の傾向を確認

## Guideline 5.2.5

WeatherKitを使用しています。天気情報が表示されるすべての画面に、タップ可能な「 Weather」表示とApple Weatherの法的帰属ページへのリンクを追加しました。

確認手順：「今日」タブ上部、または「リズム」タブの「空模様と気分」までスクロール → 「 Weather」をタップ

法的帰属リンク：https://weatherkit.apple.com/legal-attribution.html

物理デバイスで上記手順を撮影した画面収録を、App Review Informationに添付します。
